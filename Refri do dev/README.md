# 🥤 Carrossel Animado de Refrigerantes

Olá! Seja muito bem-vindo ao meu repositório. 👋

## 🚀 Sobre o Projeto
Este é um projeto de um carrossel interativo e animado utilizando **HTML5, CSS3 e JavaScript puro**. A aplicação alterna fundos, títulos e imagens de forma dinâmica e com transições suaves ao clicar nos botões de navegação.
