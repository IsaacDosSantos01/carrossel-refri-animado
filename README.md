🥤 Carrossel Animado de Refrigerantes
Olá! Seja muito bem-vindo ao meu repositório. 👋

🚀 Sobre o Projeto
Este é um projeto de carrossel interativo e animado utilizando HTML5, CSS3 e JavaScript puro . A aplicação alterna fundos, títulos e imagens de forma dinâmica e com transições suaves ao clicar nos botões de navegação.

🧠 Meu Momento Atual (Estudos)
🔰Nível : Iniciante no mundo da programação.
🎓 Contexto: Estou construindo minha bagagem de código de forma autodidata para chegar preparado na faculdade de Engenharia de Software , que começa no próximo ano!
📺 Origem: Desenvolvi este projeto acompanhando o passo a passo do tutorial do canal do Rodolfo Mori (DevClub) no YouTube, praticando a digitação de código real, lógica de programação e manipulação do DOM.
Focado em aprender e evoluir passo a passo! Se você tiver dicas ou feedbacks, sinta-se à vontade para se conectar comigo.
